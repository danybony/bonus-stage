# Security

Bonus Stage stores each user's RetroAchievements web API key encrypted on the device (Android Keystore, iOS Keychain) and only sends it to the RetroAchievements API.

If you find a vulnerability, for example a way the key could leak, please do not open a public issue. Report it privately through [GitHub's private vulnerability reporting](../../security/advisories/new). You will get an answer as soon as possible, and credit in the fix if you want it.

Security fixes go into the latest release only.
